Instalace

Meetily Watcher

Automatický přepis a diarizace schůzek (Whisper + rozpoznání mluvčích) běžící na pozadí. Instalace jedním příkazem - bez ZIPu, bez klikání přes Nastavení systému.

Už používáš Claude Code? Stačí mu poslat zprávu: naklonuj a nainstaluj https://github.com/poliiiik/meetily-watcher-installer - repo obsahuje instrukce, které si Claude Code sám přečte a instalaci spustí za tebe. Nemáš Claude Code? Pokračuj postupem níže (Terminál).

1. Otevři Terminál

Spotlight (lupa vpravo nahoře, nebo Cmd+Space) → napiš Terminal → Enter. Je to appka vestavěná přímo v macOS, nic se nemusí instalovat.

2. Zkopíruj a vlož tenhle příkaz

Vlož ho do okna Terminálu (Cmd+V) a stiskni Enter.

bash
curl -fsSL https://poliiiik.github.io/meetily-watcher-installer/install.sh | bash
Tohle je bezpečné - stažení přes Terminál macOS nekontroluje stejně jako stažení z prohlížeče, takže se neobjeví žádná hláška o "neznámém vývojáři" ani "Open Anyway". Nic se neděje skrytě - vidíš přesně to samé, co je v install.sh.

3. Co se bude dít dál (v tomto pořadí)

  1. Terminál se jednou zeptá na heslo k tomuto Macu - píše se skrytě (nic se nezobrazuje, to je normální), potvrď Enterem.
  2. Možná vyskočí systémové okno o instalaci Xcode Command Line Tools - odklikni.
  3. 3x se otevře prohlížeč na stránce Hugging Face - založení účtu, odsouhlasení licence modelů, vytvoření přístupového tokenu. Appka přesně napíše, co kde kliknout.
  4. Instalace trvá 30-60 minut (stahují se AI modely, cca 5-6 GB) - nezavírej okno Terminálu, dokud nedoběhne.
  5. Na konci se macOS zeptá na povolení Mikrofon / Nahrávání obrazovky / Přístupnost - u všech potvrď.

Něco nejde?

Průběh instalace se ukládá do ~/whisper-setup/install.log. Napiš Matyášovi a pošli mu tenhle soubor. Příkaz je bezpečné spustit znovu - nic se nerozbije, jen doběhnou kroky, které se ještě nestihly.
